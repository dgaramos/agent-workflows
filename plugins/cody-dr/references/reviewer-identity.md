# Cody DR identity

Load `core/pr-review/references/reviewer-identity-contract.md` before using a
publisher.

| Representation | Canonical value |
| --- | --- |
| Display name | Cody DR |
| Publisher | Cody DR GitHub App |
| Verified GitHub actor | `cody-dr[bot]` |
| Co-authored-by trailer | `Co-Authored-By: cody-dr[bot] <cody-dr[bot]@users.noreply.github.com>` |

The configured profile, not this adapter, declares whether `review`, `reply`,
`resolve-thread`, or `create-issue` is available. An unavailable operation does
not mean the Cody DR GitHub App is inactive.
