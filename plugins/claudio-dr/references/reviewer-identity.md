# Claudio DR identity

Load `core/pr-review/references/reviewer-identity-contract.md` before using a
publisher.

| Representation | Canonical value |
| --- | --- |
| Display name | Claudio DR |
| Publisher | Claudio DR GitHub App |
| Verified GitHub actor | `claudio-dr[bot]` |
| Co-authored-by trailer | `Co-Authored-By: claudio-dr[bot] <claudio-dr[bot]@users.noreply.github.com>` |

The configured profile, not this adapter, declares whether `review`, `reply`,
`resolve-thread`, or `create-issue` is available. An unavailable operation does
not mean the Claudio DR GitHub App is inactive.
